# Winged Air Suspension Ornithopter (WASO)
***Pronounced Oiseau***

WASO is an ornithopter inspired by the design of an Albatross. It uses a 6v Micrometal Gearmotor to power two 225mm wings composed primarily of thin membrane. The body of WASO was designed in Onshape and can be 3D printed as a single piece with minimal supports.
